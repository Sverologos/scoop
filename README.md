# Sverologo's Scoop bucket

[Scoop](https://scoop.sh/) bucket for Windows command-line tools.

## Installation

```powershell
scoop bucket add sverologos https://github.com/sverologos/scoop
```

## Available packages

| Package | Description |
| --- | --- |
| `cflsync` | Synchronize Confluence Cloud pages with local Markdown page directories. |

Install a package with:

```powershell
scoop install cflsync
```

`cflsync` installs Scoop-managed Python and Pandoc automatically.

## Updating

```powershell
scoop update
scoop update cflsync
```

## Manifests

Package manifests are in [`bucket/`](bucket/). Each manifest is maintained from
the corresponding upstream GitHub release.
